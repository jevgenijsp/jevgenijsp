### 👋 About me

Full stack developer with 12+ years of shipping software — from embedded POS terminal code to multi-tenant cloud platforms. I've spent my career on both ends of the stack: **C# / .NET** backend services and **React, Next.js & Angular** frontends, plus the architecture, integrations and infrastructure in between.

These days I'm all about the modern web stack: **Next.js, Payload CMS, PostgreSQL and serverless on Vercel/AWS**. I like systems that stay clean as they grow, and I care about developer experience as much as the final product.
